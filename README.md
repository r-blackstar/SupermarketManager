# SupermarketManager（商店管理工具箱）


---

## 功能概述

一款为超市模拟器设计的 BepInEx 插件，提供货架管理、价格管理、资源修改等便捷功能，所有功能集成在一个窗口中，按 **H 键** 即可打开。

---

## 安装方法

1. 确保已安装 [BepInEx](https://github.com/BepInEx/BepInEx)（推荐 5.x 版本）
2. 将 `SupermarketManager.dll` 复制到游戏的 `BepInEx/plugins/SupermarketManager/` 目录下
3. 启动游戏，插件会自动加载

---

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| **H** | 打开/关闭商店管理工具箱窗口 |

---

## 功能详情

### 📦 货架管理

管理商店内所有货架的商品分配。

- **一键分配（每个格子不同产品）** — 自动将可用产品分配到所有空货架槽位，每个槽位放置不同的产品，直到所有槽位填满或可用产品用完
- **刷新** — 手动刷新货架列表
- **展开货架详情** — 点击 `>` 展开单个货架，查看每个槽位的状态
- **分配/清除单个槽位** — 展开货架后可对单个槽位进行分配或清除操作
- **为所有空槽位选择产品** — 展开货架后可选择一种产品填充所有空槽位
- **填充** — 对已有产品的货架，用相同产品填满剩余空槽位
- **清除** — 清除货架上所有产品

> ⚠️ 仅主机（Host）可执行分配和清除操作，非主机玩家只能查看。

---

### 💰 价格管理

管理所有已解锁产品的定价。

- **自动定价全部** — 一键为所有产品设置自动价格（基础价 × 通胀系数 × (1 + 加价百分比)）
- **加价百分比调节** — 点击 `-10%` / `+10%` 按钮调整加价幅度
- **手动定价** — 在"新价格"输入框中输入价格，点击"设"按钮应用
- **自动价参考** — 每行显示当前加价比例下的自动计算价格，供参考
- **高价标记** — 被顾客投诉"太贵"的产品行会以红色背景高亮显示

**自动定价公式**:
```
自动价 = 基础价 × 等级通胀系数 × (1 + 加价百分比/100)
```

### 🛠️ 资源修改

修改游戏内资源和清理建筑碎块。

#### 金钱修改
- 显示当前金钱数额
- 自定义金额输入 + 增加按钮
- 快捷按钮：`+$1,000` / `+$5,000` / `+$10,000` / `+$50,000`

#### 特权点修改
- 显示当前特权点数额
- 自定义点数输入 + 增加按钮
- 快捷按钮：`+5` / `+10` / `+50` / `+100`

#### 一键清理碎块
- 一键移除场景中所有建筑碎块（锤子敲墙壁后掉落的混凝土碎片）

> ⚠️ 仅主机（Host）可执行资源修改操作。
