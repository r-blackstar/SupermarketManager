# SupermarketManager（商店管理工具箱）

***

## 快捷键

| 按键    | 功能        |
| ----- | --------- |
| **H** | 打开/关闭管理窗口 |

***

## 一、货架管理

### 1.1 货架列表

每行显示一个货架：

- **货架名称** — 游戏内对象名
- **类型** — 容器类别编号
- **已用/总槽位** — 如 `3/6`
- **商品状态** — `(空)` 灰色 / 单一商品名 / `商品名 +N种` 橙色混放

### 1.2 操作按钮

| 按钮             | 功能                        | 条件               |
| -------------- | ------------------------- | ---------------- |
| 一键分配（每个格子不同产品） | 自动为每个空槽位分配不同产品，初始数量设为满箱容量 | 需补货或管理权限         |
| 刷新             | 重新扫描所有货架                  | 始终可用             |
| 填充             | 用货架主商品填满剩余空槽位             | 有商品且未满且非混放 + 有权限 |
| 清除             | 清除货架全部商品                  | 有商品 + 有权限        |

### 1.3 展开货架详情

点击 `>` / `v` 展开/收起槽位：

- **空槽位**：显示"(空)"，可点"分配"选择产品，或点"为所有空槽位选择产品..."批量填充
- **已占用槽位**：显示商品名，可点"清除"移除

选择产品时显示兼容列表（商品名/品牌/等级）：

- **设槽位** — 仅放入当前选中空槽位
- **设全部** — 放入该货架所有空槽位

## 二、价格管理

### 2.1 批量操作

| 按钮          | 功能              |
| ----------- | --------------- |
| 自动定价全部      | 一键设置所有产品为自动计算价格 |
| -10% / +10% | 调整加价百分比（最小0%）   |
| 加价显示        | 当前加价值（默认10%）    |

公式：`基础价 × 等级通胀系数 × (1 + 加价百分比/100)`

### 2.2 产品列表

每行一个产品：

| 字段  | 说明              |
| --- | --------------- |
| 名称  | 商品中文名           |
| 品牌  | 商品品牌            |
| 等级  | Tier等级          |
| 基础价 | 系统基础单价          |
| 当前价 | 当前售价            |
| 新价格 | 输入框，手动输入后点"设"应用 |
| 自动价 | 按当前加价公式计算的参考价   |

被顾客投诉"太贵"的产品行**红色背景**高亮。

## 三、资源修改

### 3.1 金钱

- 显示当前金额
- 自定义金额输入 + "+增加"按钮
- 快捷按钮：`+$1,000` / `+$5,000` / `+$10,000` / `+$50,000`

### 3.2 特权点

- 显示当前特权点数
- 自定义点数输入 + "+增加"按钮
- 快捷按钮：`+5` / `+10` / `+50` / `+100`

### 3.3 刷新数值

点击"刷新当前数值"重新读取游戏实际数据。

### 3.4 一键清理碎块

移除场景中所有建筑碎块（锤子敲墙壁产生的碎片），逐个调用游戏移除命令。

### 3.5 回收空箱子

扫描出货区所有箱子，找出无剩余商品的空箱，逐一销毁并按每个$8退回资金。

## 四、增强功能

### 4.1 补货提醒

| 按钮     | 功能                       |
| ------ | ------------------------ |
| 扫描货架库存 | 扫描所有货架商品库存，统计容量、余量、未上架数量 |
| 全部采购   | 为所有缺货/不足商品各采购1箱，资金不足自动停止 |

扫描后显示：总商品种数 + 需补货种数（红色）/ 库存充足（绿色）

商品列表每行：

| 字段   | 说明                               |
| ---- | -------------------------------- |
| 商品   | 商品中文名                            |
| 槽位容量 | 每个槽位最大存放量（满箱容量）                  |
| 槽位余量 | 所有槽位中最少剩余量                       |
| 未上架  | 出货区该商品总件数，无则显示"-"                |
| 状态   | 缺货（红色，余量=0）/ 不足（橙色，余量<5）/ 充足（绿色） |
| 操作   | 余量<5时显示"+1箱"按钮，点击直接采购1箱到出货区      |

### 4.2 快速雇佣

| 按钮      | 功能                 |
| ------- | ------------------ |
| 刷新可雇佣列表 | 读取今日候选人数据          |
| 全部雇佣    | 一键雇佣所有候选人，受最大员工数限制 |

显示：已雇佣人数/最大员工数

每位候选人一张卡片：

**第一行**：候选人名称 / 薪资 / 最强技能及数值（绿色≥7 / 黄色4\~6 / 橙色<4）/ "雇佣"按钮

**第二行** — 七项能力值（颜色同上）：

| 能力 | 说明      |
| -- | ------- |
| 收银 | 收银台工作效率 |
| 补货 | 补货上架速度  |
| 仓储 | 仓库管理能力  |
| 安保 | 安全巡逻效果  |
| 技术 | 设备维修技能  |
| 订购 | 订货补货判断力 |
| 制造 | 生产加工能力  |

### 4.3 快速传送

预设位置（每行一个"传送"按钮）：

| 位置    | 坐标来源                         |
| ----- | ---------------------------- |
| 超市正门  | 固定坐标                         |
| 员工休息室 | 从游戏restSpotOBJ对象读取           |
| 出货处   | 从游戏merchandiseSpawnpoint对象读取 |
| 经理室   | 从游戏UIPerksParent对象读取         |
| 垃圾桶旁边 | 从游戏trashSpotOBJ对象读取          |

自定义位置保存：

- 输入名称 → 点"保存" → 记录当前坐标+朝向
- 自定义位置显示在预设下方，名称黄色标识
- 上限20个

## 五、经营分析

### 5.1 利润统计

点击"计算利润"后显示所有产品利润数据。

统计：总商品种数 + 亏本种数（红色警告）

表格（按利润率从低到高排序）：

| 字段   | 说明                   |
| ---- | -------------------- |
| 商品   | 商品中文名                |
| 成本   | 通胀后单位成本（基础价×通胀系数）    |
| 售价   | 当前售价                 |
| 利润/件 | 售价-成本，正绿/负红粗体        |
| 利润率  | (利润÷成本)×100%，正绿/负红粗体 |
| 等级   | Tier等级               |

亏本商品整行**红色背景**高亮。

### 5.2 销售热力图

点击"刷新销售数据"后分析每种商品销售状态。

五级热力标记：

| 标记  | 颜色 | 判定            |
| --- | -- | ------------- |
| 畅销  | 绿色 | 货架有余量且无标记     |
| 太贵  | 黄色 | 在昨日"太贵"投诉列表中  |
| 库存低 | 橙色 | 货架余量≤5        |
| 缺货  | 红色 | 货架余量=0        |
| 找不到 | 紫色 | 在昨日"找不到"投诉列表中 |

表格（按热力等级从高到低排序）：

| 字段   | 说明                          |
| ---- | --------------------------- |
| 商品   | 商品中文名                       |
| 货架库存 | 所有货架总数量                     |
| 状态   | 五级热力标签之一                    |
| 标记   | 所有问题标签组合，如"太贵 缺货"，无问题显示"正常" |

### 5.3 每日收支概览

显示游戏内第N天财务数据，点"刷新"更新。

**收入**：日收益

**支出**：商品采购 / 员工薪资 / 租金 / 电费 / 其他费用

**净利润**：收入-全部支出，正绿/负红粗体

**其他统计**：今日顾客数 / 被抢劫次数及损失金额 / 卫生投诉次数

## 权限说明

### 主机与客机权限对照

| 功能                 |  主机 |  客机（有权限）  | 客机（无权限） |
| :----------------- | :-: | :-------: | :-----: |
| 货架列表查看             |  ✅  |     ✅     |    ✅    |
| 货架分配/清除/填充         |  ✅  | ✅ 补货或管理权限 |  ❌ 仅查看  |
| 价格列表查看             |  ✅  |     ✅     |    ✅    |
| 价格修改/自动定价          |  ✅  | ✅ 定价或管理权限 |  ❌ 仅查看  |
| 资源修改（金钱/特权点/碎块/空箱） |  ✅  |   ✅ 管理权限  |  ❌ 不可用  |
| 补货扫描/查看            |  ✅  |     ✅     |    ✅    |
| 补货采购/+1箱           |  ✅  | ✅ 补货或管理权限 | ❌ 无操作按钮 |
| 快速雇佣               |  ✅  |   ✅ 管理权限  |  ❌ 不可用  |
| 快速传送               |  ✅  | ✅ 补货或管理权限 |  ❌ 不可用  |
| 经营分析（全部）           |  ✅  |     ✅     |    ✅    |

### 权限变更机制

- **主机**始终拥有所有权限，无需额外操作
- **客机**的权限由房主在游戏内授予，权限类型对应关系：
- 房主授予客机对应权限后，客机即可使用对应功能，无需重新进入游戏
- 权限每5秒自动刷新检测，房主随时可收回权限
- 权限检测失败3次后停止重试，避免持续报错；重新打开窗口会强制刷新权限
